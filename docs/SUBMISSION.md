## STEP 2 — 배포 (키 필요)

Vercel 개인 계정이라 자동화 도구로는 프로젝트를 만들 수 없다. 직접 실행한다.

```bash
cd office-firewall

# 1) 별칭 선점 — 프로젝트 생성 "즉시" 할 것
#    (이전 운영 앱에서 alias 를 뺏긴 사고가 있었다)
npx vercel link --project office-firewall --yes

# 2) 환경변수 (Production)
npx vercel env add ANTHROPIC_API_KEY production
npx vercel env add OFW_MODEL production        # 값: claude-opus-5

# 3) 배포
npx vercel --prod
```

배포 후 확인:

- [ ] 페이지가 뜨는가
- [ ] 분석 실행 시 모드 배지가 **LIVE** 인가 (MOCK 이면 키가 안 잡힌 것)
- [ ] `vercel.json` 의 `maxDuration: 25` 가 현재 플랜에서 거부되지 않았는가
      (빌드 로그에 경고가 뜨면 15 로 낮추고, 그때는 `CALL_TIMEOUT_MS`(현재 9초)도
      함께 확인 — 타임아웃 × 재시도가 함수 제한을 넘으면 안 된다)

## STEP 3 — LIVE 실측 (키 필요, 배포 후)

지금까지 모든 수치는 MOCK 기준이다. 아래는 **키를 꽂고 한 번 돌려야만** 나온다.

- [ ] 골든 5종을 배포본에서 한 번씩 실행
- [ ] 응답 지연시간 기록 (결과 패널 우하단에 `model · ms` 로 표시된다)
- [ ] 토큰 사용량 기록 (같은 줄에 `in/out tokens`)
- [ ] **프롬프트 캐시가 실제로 먹는지 확인** — 2회차 이후 `cache_read_input_tokens`
      가 0 이면 시스템 프롬프트(~1K 토큰)가 모델의 최소 캐시 길이에 미달한 것이다.
      0 이어도 동작에는 문제없다. 비용 계산에서 캐시 절감을 빼면 된다.
- [ ] README 의 "LIVE 모드 실측치는 API 키 투입 후 갱신한다" 문장을 실제 수치로 교체

## STEP 4 — 시연 (키 불필요, 지금 연습 가능)

**90초 안에 차별점 3개를 다 보여주는 순서.** 각 단계가 README 의 차별점과 1:1로 맞는다.

| # | 조작 | 말할 것 | 시간 |
|---|---|---|---|
| 1 | 실제 메시지 붙여넣기 (아래 대본) | "이런 메시지, 거절도 수락도 애매하죠" | 10s |
| 2 | **"전송될 내용 확인하기"** 클릭 | "이름·전화는 브라우저에서 이미 가려졌습니다. 서버로 나가는 건 이 텍스트입니다" | 20s |
| 3 | 실행 → X-Ray | "92점. 주말 침범 + 범위 불명이 겹쳤습니다" | 15s |
| 4 | **"판정 근거 보기"** 펼치기 | "이 점수는 AI가 준 게 아니라 코드가 계산한 값입니다. 같은 입력이면 항상 같은 점수가 나옵니다" | 20s |
| 5 | 정상 업무 메시지로 재실행 | "과잉 경보를 안 한다는 게 중요합니다. 이건 16점, 정상입니다" | 15s |
| 6 | 영수증 발급 | "공유용 카드. 옆에 무료 심리상담 링크가 있습니다" | 10s |

**시연 대본 (고위험)**
```
박지훈 팀장님 주말에 미안한데, 월요일 오전에 대표님 보고가 잡혀서요.
시간 날 때 가볍게 한번 봐주시면 좋을 것 같아요. 급한 건 아닙니다!
```
숨은 속사정 칸: `김수진 대리한테 010-1234-5678 로 이미 확인함`
→ 이름 2개·전화 1개가 가려지고 직급·시간은 남는 게 화면에 그대로 보인다.

**시연 대본 (정상 업무 대조군)** — 16점 green
```
9월 15일 14시까지 배너 시안 2종 부탁드립니다.
사이즈는 1200x600, 문구는 첨부 파일 3페이지 기준입니다.
```

> **시연 안전장치**: 모델 호출이 실패해도 화면은 비지 않는다. 로컬 룰엔진으로
> 자동 폴백하고 배지가 `LOCAL` 로 바뀐다(실측 확인함). 정 불안하면 배포 환경변수에
> `OFW_FORCE_MOCK=1` 을 넣어 아예 모델을 안 부르게 할 수도 있다.
